# Что я включил в первую версию

Я собрал полный путь: выбранные OMS/PSP файлы → проверка/raw → immutable facts → воспроизводимая сверка → карточка с источниками → решение с автором и причиной → согласованный CSV. Settlement и dbt объясняют комиссии/итоги отдельно от очереди. Backfill, backup/restore receipt, account recovery, health/metrics и изолированный Compose закрывают сопровождение одного экземпляра.

Я сохранил30 исходных историй и последовательность review. В процессе реальных проверок исправил несовместимость Prefect/FastAPI, Docker сетевой доступ и Caddy capability, PostgreSQL FOR SHARE grant, Browser Origin:null. Не выдаю первоначальные неуспешные прогоны за успешные. Финальные gates и фактическая публикация — [RELEASE_CHECKLIST](RELEASE_CHECKLIST.md).

Я поддерживаю Linux x86_64/локальный Compose. Для нового экземпляра использую README; для обновления и восстановления — HANDBOOK/BACKUP. Старт пустой, синтетический demo явно включаю сам. Я не меняю финансовые данные через интерфейс и не выполняю платежей. Исторические corrections report-only, автоматических schedules/PSP API/retention/HA/SSO нет. Это законченный первый объём, дальнейшие возможности требуют отдельной истории и проверок. Учебное происхождение и измеренные границы сохраняю.
