# Словарь проекта

| Термин | Значение в CommerceGuard |
| --- | --- |
| OMS | Источник заказов и утверждённых ожиданий capture/refund |
| PSP | Источник фактов оплаты/возврата; в v1 один провайдер |
| Capture | Подтверждённое списание, не попытка и не авторизация |
| Refund | Подтверждённый возврат; размер положительный, смысл задаёт kind |
| Minor units | Младшие единицы валюты: для RUB копейки |
| Settlement | Перечисление провайдера с учётом комиссии, зерно batch |
| Snapshot | Согласованный полный снимок ожиданий, не случайный набор строк |
| Batch | Единица приёма файла/пакета с manifest и checksum |
| Raw | Неизменяемый исходный артефакт; не публичные реальные данные |
| Quarantine | Неинтерпретируемый вход, требующий исправления контракта/источника |
| Finding | Вычисленное отклонение конкретного правила на конкретном run |
| Case | Операционная карточка проблемы и история решений людей |
| Evidence | Идентификаторы исходных фактов, поддерживающих вывод |
| Lineage | Путь от файла и строки через модель и run к показателю/кейсу |
| Cutoff/as_of | Граница времени, на которую система формирует знание |
| Effective/occurred time | Когда состояние/операция действовали в бизнесе |
| Observed time | Когда система впервые узнала о состоянии/операции |
| Watermark | Описанная граница обработанных/полученных данных источника, не просто текущее время |
| Backfill | Пересчёт явного прошлого диапазона с определённой версией правил и знания |
| Idempotency | Повтор одной смысловой команды не добавляет второй смысловой результат |
| WIP | Незавершённая активная работа, ограниченная политикой доски |
| Sprint Goal | Одна цель спринта, связывающая выбранные истории |
| Authored/unverified | Исходники написаны, но работоспособность не подтверждена |
