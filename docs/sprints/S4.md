# S4 — я создаю рабочее место финансового аналитика

Я прохожу истории последовательно, с WIP1 и отдельными Draft PR. Моя цель —
видимый путь от очереди до сохранённого решения, без изменения финансовых фактов.

| История | Зачем я беру её | Критерий выхода |
| --- | --- | --- |
| CG-401 | Я нахожу карточку и проверяю evidence | Фильтры, bounded pages, run context, empty state, read-only |
| CG-402 | Я определяю действующего оператора | Local-only, server sessions, CSRF, роли, отсутствие default password |
| CG-403 | Я веду разбор | Request identity, version conflict, assignment/comment и audit одним COMMIT |
| CG-404 | Я фиксирую решение | Причина, close/reopen, история, presence отдельно |
| CG-405 | Я передаю срез | Безопасный export с валютой/cutoff/run context |

Я не объявляю истории Accepted автоматически. Фактические шаги и проверки веду
в PROGRESS, KANBAN, WORKLOG и VALIDATION. Каждая опубликованная ветка сохраняет
предыдущий срез; main остаётся навигацией до отдельного решения о merge.
